## 🌟 项目亮点

1. **极简浅色杂志/文档风设计 (Editorial Clean)**：
   - 柔和温润的米白纸张底色（`#FAF9F6`），高对比度石墨黑字体排版；
   - 衬线与现代无衬线中英混排，精心设计的微交互与数据看板。
2. **完整真实的经历沉淀**：
   - 教育背景：电子科技大学通信工程本科（数学竞赛/数模省级奖项） + 香港中文大学（深圳）通信工程硕士在读；
   - 核心实习：港中深高拟人表情机器人团队研助（面部舵机控制、ROS2 链路、Audio2Face 转 RKNN NPU 部署）+ 科大讯飞运营技术支持（企业网络降本与管理流程系统化）；
   - 个人作品：涵盖 AI 问答评测 Golden Set (M1)、Agent 核心调度机制、Linkus 校园地图社交 App、PX4 无人机视觉控制及多机定位算法。
3. **独立标准简历视图与 A4 打印优化**：
   - 提供 `/resume.html` 专属简历页；
   - 内置矢量级 `@media print` 规则，点击“打印 / 导出 PDF”即可无缝导出不跨页截断的标准求职简历。
4. **可视化后台与智能简历导入中心**：
   - 提供 `/admin.html` 可视化管理面板；
   - 可以在网页端直接增删改所有经历并即刻保存在本地；
   - 支持粘贴 **LinkedIn / 大厂招聘平台** 的简历文本，智能算法一键抽取姓名、联系方式、院校与实习经历并自动填充。

## 🛠️ 日常维护与更新说明

### 方式一：在网页管理后台直接修改（最直观推荐）
1. 访问网站右上方导航栏的 **「⚙️ 后台管理」**（或直接访问 `https://laid966.github.io/admin.html`）；
2. 修改任何文字、添加新的实习或项目卡片，点击 **“保存并即刻生效”**；
3. 点击 **“复制 site-data.js 代码”**，用复制的内容覆盖本地 `js/site-data.js`；
4. 在终端执行 `git commit -am "update resume"` 和 `git push`，即可让全球访客永久看到最新版！

### 方式二：直接编辑代码
打开 `js/site-data.js`，修改里面的 JavaScript 对象属性即可。
